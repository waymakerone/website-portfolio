# Portfolio & Creative

A visually-driven portfolio for designers, photographers, artists, filmmakers, and creative professionals. Minimal UI that lets the work speak for itself. This blueprint strips away the noise so your projects, your craft, and your creative identity take centre stage.

## What You Get

- **Hero / Introduction** -- Your name, discipline, and a hero image that sets the creative tone
- **Work / Projects Grid** -- 6-12 projects with images, filterable by category so visitors can browse your range
- **About** -- Bio, creative philosophy, and notable clients or awards that establish credibility
- **Process** -- How you work in 3-5 steps, so potential clients know what to expect
- **Contact** -- Email, social links, and availability status so the right people can reach you

## Two Ways to Build

### IDE Path (Claude Code, Cursor, Codex)
1. Clone this blueprint into your project
2. Open `CLAUDE.md` -- it's the router file for your AI coding tool
3. Read the PRD in `docs/01-planning/product-requirements/`
4. Open the build prompt in `docs/02-working/prompts/active/`
5. Point your AI tool at the prompt and build

### Host Direct Path (Claude Desktop)
1. Open Claude Desktop with WaymakerOS connected
2. Say: "Build a portfolio website for me -- I am a freelance brand designer named Alex Chen."
3. Answer the questions about your work
4. The AI builds and deploys your website via Host Direct

**Estimated build time:** ~15 minutes with either path.

## Design Guidance

| Token | Value |
|-------|-------|
| Colour palette | Minimal -- black, white, one accent colour. Dark mode option. |
| Typography | Distinctive type pairings that reflect creative identity |
| Mood | The work IS the design -- large images, generous whitespace, nothing competing for attention |

## Prerequisites

- WaymakerOS account (for deployment to Waymaker Host)
- Business content (text, photos, details for each section)
